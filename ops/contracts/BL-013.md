# Sprintcontract — BL-013 Portal R3 als site-root

**Doel:** `ninotopo.nl/` toont het portal (landkiezer) met de goedgekeurde R3-merkassets; de Italië-app staat op `/italie/`.
**Waarom nu:** domein gekocht, artwork goedgekeurd (14-11), besluit Dennis: optie A (portal live met de huidige Italië-versie, V3 volgt via BL-005).
**Bouwer:** hoofdsessie (Fable) · **Evaluator:** evaluator-subagent · **Max runs:** 1

## Scope
- Wel: `portal/` overnemen van `feat/nino-topo-portal-r2`; Logo R3.1, Nino Welcome R3, Favicon R3 aansluiten; `scripts/build-site.mjs`, `scripts/verify-site.mjs`, `vercel.json`, `package.json` (script `build:site`).
- Niet: wijzigingen aan de Italië-app (`index.html`, `scripts/*engine*`), V3, Frankrijk-route, productie-deploy of domeinkoppeling (G4).

## Acceptatiecriteria
| # | Criterium | Hoe getoetst | Verwacht |
|---|---|---|---|
| 1 | Site-indeling klopt | `npm run build && npm run build:site` | `dist/index.html` = portal, `dist/italie/index.html` = app, "Site-check: OK" |
| 2 | App ongewijzigd | `git diff origin/main -- index.html print.html scripts/learning-engine.js scripts/route-engine.js` | leeg |
| 3 | Bestaande tests groen | `npm run lint && npm test` | groen |
| 4 | Geen kapotte verwijzingen | Chrome via Playwright op `dist/` (1440×900, 1080×810, 810×1080, 390×844) | 0 HTTP ≥ 400, 0 console-fouten, 0 kapotte afbeeldingen |
| 5 | Geen horizontale scroll, Nino overlapt geen kaart | zelfde run | `scrollWidth ≤ innerWidth`, geen overlap |
| 6 | Italië-knop werkt | klik "Start leren" | opent `/italie/`, titel "Topo Italië · leer de kaart" |
| 7 | R3-assets byte-gelijk aan `art/master` | `sha256sum -c` tegen `SHA256SUMS.txt` van `art/master` | OK |
| 8 | Frankrijk heeft geen verzonnen route | bron | `france:null`, toont "Leeromgeving volgt" |
| 9 | Contrast knoppen | `verify-site.mjs` | ≥ 4,5:1 |

## Stopcriterium
1–9 PASS. Daarna G1 (visuele GO Dennis op de preview) en G4 (live + DNS), buiten dit contract.

## Risico en rollback
Productie-URL van de app verschuift van `/` naar `/italie/`. Voortgang blijft bewaard (localStorage is per domein, niet per pad). Rollback: revert van de merge-commit; `vercel.json` valt terug op de oude build.
