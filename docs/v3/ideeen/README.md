# Ideeën V3.1

## Uitstapjes (DECISIONS 2026-11-10)

`UIT-torino-concept.webp` toont Nino die een bal trapt op Piazza San Carlo in Turijn. Het is de eerste kandidaat-scène voor het prototype.

- **Goedgekeurd als concept:** het uniform, geen clubtenue en geen tekst op borden.
- **Scriptlogo op de Vespa:** mag blijven (besluit eigenaar, 10-11). Het is klein en onleesbaar, en het past bij de Vespa als vast motief. Wordt de app ooit commercieel verspreid, dan opnieuw bekijken.
- **Formaat later:** afhankelijk van de vorm van het uitstapje (scène of postkaart). Daarna volgt de artworkpijplijn `art/v3-render-assets`.
