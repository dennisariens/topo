# Instructions for coding agents

1. Read `docs/PROJECT_STATE.md` first; read `docs/MAP_SYSTEM.md` before map or geography changes and `docs/DECISIONS.md` before product decisions.
2. Inspect the embedded `ITEMS`, `CONTEXT_LAND`, `italy`, `NAME_ANCHORS`, and worksheet image in `index.html` before adding or moving coordinates. The current repository has no independent GeoJSON source; obtain and document a reliable source before replacing mapped geometry. Do not treat chat screenshots as source data.
3. Never approximate a feature when reliable geographic geometry is available. Preserve geographic positions across styling changes; distinguish visible geographic shape from touch tolerance. Never silently replace a shape with a box or move a feature into sea to make it easier to tap.
4. Keep the 45 learning items, city grouping, quiz, feedback, saved mistakes, and reset working unless the assigned change explicitly modifies them. Preserve corrected positions including San Marino, Bologna, Sicily label, Etna, the Po endpoint, and the Dolomites zone. Run the geographic validation after map edits.
5. Treat the self-contained `index.html` as the v6-derived map/content source and `scripts/learning-engine.js` as the exact source for its first inline script. They must match (`npm run lint` enforces it). No external runtime scripts: breaking that makes direct downloads inert. Do not maintain a second independent copy of geographic coordinates. Historical HTML versions are superseded.
6. Add targeted regression coverage for geography and quiz changes. Run `npm run lint`, `npm test`, and `npm run build`; `npm run typecheck` is a documented no-op until TypeScript or a type checker is added. Record any unavailable browser check explicitly.
7. Update `docs/PROJECT_STATE.md` after meaningful implementation work. Append decisions to `docs/DECISIONS.md`; mark superseded decisions explicitly without erasing history. Intended behavior belongs in the other docs, not in undocumented agent memory.
8. `npm run dev` serves the root at port 8000. `npm run build` regenerates `print.html`, the identical downloadable HTML, and `dist/index.html`, `dist/print.html`, `dist/printboek.pdf`. After content changes, run `python3 scripts/generate-pdf.py` for the booklet at `output/pdf/`; do not edit generated files manually. `npm test` runs dependency-free Node validation including a full button smoke flow. `vercel.json` configures static deployment; no framework or CI.

Priority: geographic correctness → educational effectiveness → clarity → usability → consistency → engagement. See `docs/ROADMAP.md` for the single recommended next package.
