## Verification and reproducibility

Use supported Node **24.15.0+**. On this machine:

```sh
npx --yes --package=node@24.15.0 -c 'npm ci && npm run lint && npm test && npm run build'
```

After editing presentation sources, rebuild first so lint can verify exact embedded source/asset equality. No external runtime dependency was added. A narrowly scoped compatible dev-only lockfile update changes `undici` 8.11.2 → 8.12.3 to remove newly reported npm advisories in the existing jsdom dependency tree; `npm ci` reports zero vulnerabilities after that update.

Browser evidence is generated by actual controls and true engine results:

```sh
python3 -m http.server 8015 --bind 127.0.0.1
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
  TOPO_URL=http://127.0.0.1:8015/ \
  node scripts/qa-nino-art.mjs
```

The runner accepts `CHROME_PATH` and `QA_OUTPUT`. It starts with clean disposable contexts, completes the initial stages and full 12-task city Gold challenge, captures the actual 24th-retrieval trip, checks earned/replayed/missed Gold and six-task pauses, checks a 2/6 mixed round, reload/resubmission, and tests all six embedded images offline in **both** actual downloadable files. For responsive Arrival/Gold screenshots it reuses the legitimately played pre-final-answer save and submits the remaining answer; no production scene switch or fabricated reward is introduced.

Actual tested browser: Chrome/Chromium **156.0.8078.4**, desktop **1440×1000**, iPad-size **820×1180 / 1180×820**, phone **390×844 / 320×568**. Reduced-motion, keyboard, decode, long Dutch text, fixed map ratio, non-overlapping inline art, no horizontal page overflow, pending-art fallback and image-error recovery are checked. Browser run reports zero page errors and zero external requests. This is viewport/touch emulation, not a physical iPad pass.

Required regression coverage includes unchanged 45 IDs, all eleven chapters, point/write histories, aliases, migration and strict backups, daily replay credit, reset scopes, reward rollover/idempotence, neutral overlap picker, geography/static parity and original print freshness. Learning/reward engine sources and original print HTML/PDF are preserved. Additional art-specific tests cover role gates, immutable asset bytes, future slots, fallback, and progress invariants.
